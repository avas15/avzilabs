# Bedstead

`bedstead-subset.woff2` is a subset of **Bedstead** by Ben Harris (bjh21),
an outline font reproducing the Mullard SAA5050 Teletext Character Generator,
the chip behind BBC Micro MODE 7 and Ceefax.

Source: https://bjh21.me.uk/bedstead/

**Licence: public domain.** The generating program and all newly designed
glyphs were released into the public domain by the author, and the original
SAA5050 bitmap font is believed to be public domain in the UK under section 55
of the Copyright, Designs and Patents Act 1988.

Subset to latin, digits and display punctuation, then converted to WOFF2.
Regenerate with `fonttools subset`; see the commit that introduced this file.
