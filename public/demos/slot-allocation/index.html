03Pipeline architecture

The demo pipeline in etl/pipeline_demo.py is a reduced version of one I operate daily. Every property below is deliberate and exercised by the code.

Run it yourself

python data/build_demo_db.py
python etl/pipeline_demo.py --dry-run
python etl/pipeline_demo.py
python etl/pipeline_demo.py --simulate-outage
python etl/news_updater.py

Seeded and deterministic — the same inputs produce byte-identical output.

Fail-safe behaviour

The property I care most about. With --simulate-outage:

[DEGR] change_detect  upstream unreachable;
                      last-good data retained
source degraded — exiting cleanly

It does not half-write, does not truncate, and does not report success. A pipeline that fails loudly and leaves yesterday's good data intact beats one that silently publishes a partial today.

04Entity resolution

Reconciling third-party names to an internal master is the unglamorous work that decides whether every downstream number is right. The demo warehouse ships deliberately messy aliases.

Tiered matching

TierRuleAction
1 exactcanonical / legal / known alias, same marketauto-link
2 fuzzynormalised score ≥ threshold, same marketlink + log for review
3 unmatchedno confident matchkept unlinked, never guessed

Normalisation strips legal suffixes and market qualifiers — but never to an empty string, because for some carriers the industry word is the brand.

The guard that matters

If two source entities both match one internal entity in the same market, linking both silently merges two companies' histories into a single series. The result looks plausible and is wrong.

collision: ARL / "Aurora Air"
  keep    Aurora Air      (1.00)
  demote  Aurora Airways  (0.86)  → unlinked

Genuine mergers are handled by an explicit successor rule, never by name similarity.

05Scheduled external feed

A polling job with cache revalidation and graceful degradation. Pulls from Wikipedia's public REST API — openly licensed and deliberately unrelated to any client domain.

ETag / If-None-Match revalidation means an unchanged poll costs one 304 and no parsing. Offline, it serves the cache and marks the run degraded rather than failing. Content from Wikipedia, CC BY-SA 4.0.

07How this demo is sanitised

Nothing here derives from client work.
  • The domain is airport slot allocation — chosen as a structural analogue, not a disguise for the real one.
  • All data is generated by build_demo_db.py from a seeded RNG. No real figures, entities or geographies.
  • Table and column names are original to this demo. No production schema, identifier or naming convention is reproduced.
  • Carriers, airports and groups are invented and do not correspond to real organisations.
  • Client systems in §06 are described at the level of engineering approach only — no code, data or schema.
  • The external feed is Wikipedia's public API under CC BY-SA.
